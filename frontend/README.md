# Campuslytics — Frontend

React + Redux Toolkit + Tailwind CSS (Vite). See the root `README.md` (one level up) for full setup
instructions for the whole project (backend + frontend together).

Quick start:
```bash
npm install
cp .env.example .env
npm run dev
```
Runs on http://localhost:5173 and expects the backend API at the URL set in `.env` (`VITE_API_URL`).
